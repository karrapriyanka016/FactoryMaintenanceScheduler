# Project Statement

## Title
Factory Maintenance Scheduler

## Problem Statement
Factories depend on machines that may operate for long periods under different workloads. Maintenance teams need a practical way to track machines, record faults, preserve maintenance history, and decide which machine requires attention first. The proposed system provides a command-line Java solution for organizing these activities and generating a prioritized maintenance queue.

## Scope
The project covers machine registration, issue reporting, maintenance-history recording, priority calculation, scheduling support, and summary reporting. It is designed as an academic prototype and does not directly control industrial equipment.

## Target Users
- Factory maintenance supervisors
- Maintenance technicians
- Plant administrators

## High-Level Features
1. Machine registration and tracking
2. Fault/issue reporting
3. Maintenance history
4. Priority scoring
5. Maintenance queue generation
6. Factory summary reports
7. Preventive-maintenance plans and due-status checks
7. CSV-based persistent storage
